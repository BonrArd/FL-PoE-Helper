Dúvidas

Isso é permitido pela GGG?

O programa só lê o log do jogo e o texto do item que você copia. Cada tecla gera uma única cópia do item, como no Awakened PoE Trade, e nenhuma ação no servidor. Não mexe na memória do jogo e não automatiza jogabilidade. Mesmo assim, use por sua conta.

A IA é paga?

Sem configurar nada, o botão IA abre o Claude no navegador com a pergunta e os dados da build prontos, usando a sua conta normal. Para receber a resposta dentro do programa, dá para colocar a sua própria chave da API da Anthropic (cobrada à parte). A chave fica só no seu PC.

Serve para outras builds?

Sim. Na tela inicial, cole o link do seu guia (Path of Building, pobb.in, pastebin ou Mobalytics) ou use sem guia, só com as dicas de cada ato.

Onde ficam as minhas configurações?

Em %APPDATA%\FL PoE Helper. Tem um botão "Pasta de dados" nas Configurações.

O antivírus reclamou. É vírus?

Não. O .exe é gerado com PyInstaller e não tem assinatura de empresa, o que às vezes gera um alarme falso. O código está todo aberto no GitHub e você pode rodar direto pelo Python, se preferir.
